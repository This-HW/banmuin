# bin/

실행 래퍼 스크립트 (POSIX 셸). 실제 마케팅 로직은 들어있지 않습니다.
락·킬스위치·로그 디렉토리 뼈대만 담당하고, 단계 목록을 출력하면
AI 에이전트(오케스트레이터)가 SPEC에 따라 각 단계를 수행합니다.

| 스크립트 | 용도 |
|---|---|
| `run.sh` | 일일 루틴 실행 (`--business`, `--dry-run`, `--stage` 지원) |
| `retry.sh` | 실패 단계 재시도 |
| `kill.sh` | 킬 스위치 발동 (`state/KILL` 생성) |
| `resume.sh` | 킬 스위치 해제 |
| `dlq.sh` | DLQ(`dead_letter.jsonl`) 조회·복구 |

- **실행하는 이**: AI 에이전트 또는 사람 (수동 실행 가능)
- **쓰는 이**: 사람 (기여자)
- **규칙**: 여기에 채널 API 호출·발행 로직을 넣지 마세요.
  특정 OS 전용 명령어를 쓰지 마세요 (POSIX 셸·UTF-8·LF).
