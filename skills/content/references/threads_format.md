# 스레드 포맷 가이드

content 스킬이 Threads 포스트를 쓸 때 이 체크리스트를 전부 통과해야 한다.

## 분량·수량
- [ ] 포스트당 500자 이내 (Threads 제한 준수)
- [ ] `businesses/<slug>/config.yaml`의 `threads.max_per_day` 준수 (일 상한)

## 형식
- [ ] 단독 포스트, 또는 2~4개 묶음의 연결 스레드
- [ ] 연결 스레드는 API reply 체인으로 엮이도록 순서 번호를 명시 (`1/3`, `2/3` …)

## 구조
- [ ] 첫 문장이 스크롤을 멈추게 하는 훅 (질문·공감·역설 중 하나)
- [ ] 본문: 한 가지 메시지에 집중 (여러 주제를 한 포스트에 섞지 않음)
- [ ] 마무리: 다음 행동 유도 (댓글·저장·프로필 링크 중 하나, 과도한 CTA 금지)

## 해시태그
- [ ] 3개 이내 (`businesses/<slug>/knowledge/07_채널전략.md`의 채널 톤에 맞춤)

## 금지 사항
- [ ] 500자 초과 금지 (초과 시 나누거나 줄임)
- [ ] 근거 없는 주장·과장 표현 금지
- [ ] `businesses/<slug>/knowledge/06_브랜드보이스.md`의 금지어 미포함
- [ ] 블로그 글을 그대로 붙여넣기 금지 — 스레드 말투로 재작성 필수

## 검수 연계
- 이 체크리스트는 품질 게이트 1차 검수(규칙 기반)의 스레드 항목으로 그대로 사용된다.
