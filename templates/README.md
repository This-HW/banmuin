# templates/

새 사업을 시작할 때 복사하는 빈 템플릿 모음. 사업 실데이터는 들어있지 않습니다.

| 파일 | 용도 |
|---|---|
| `knowledge/00~10` | 사업 정본 지식 11종 (사업개요·상품·가격·페르소나·FAQ·후기·브랜드보이스·채널전략·승인기준·경쟁사·용어집) |
| `config.yaml` | 채널·스케줄·예산·게이트 설정 양식 |
| `secrets.env.example` | 시크릿 양식 (복사 후 값 입력, 절대 커밋 금지) |
| `content_calendar.md` | 주간 콘텐츠 캘린더 양식 |

- **읽는 이**: 새 사업을 시작하는 사람, 온보딩을 돕는 AI 에이전트
- **쓰는 이**: 사람 (기여자). 템플릿 구조 변경 시 `docs/onboarding.md`의 매핑표도 함께 갱신합니다.
- **규칙**: 템플릿에 실제 사업 데이터·시크릿 값을 넣지 마세요. `[작성 필요]` 플레이스홀더를 유지하세요.
