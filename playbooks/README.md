# playbooks/

브라우저 자동화 도구(기본값: Aside)에 전달하는 작업 지시서 (`*.task.md`).
각 플레이북은 사전조건 → 단계 → 성공 기준 → 실패 보고 형식을 따릅니다.

| 플레이북 | 용도 |
|---|---|
| `naver-blog-publish.task.md` | 네이버 블로그 발행 |
| `naver-blog-unpublish.task.md` | 네이버 블로그 발행 취소/삭제 |
| `cardnews-render.task.md` | 카드뉴스 HTML 렌더링 |

- **읽는 이**: AI 에이전트 (발행 단계에서 브라우저 도구에 전달)
- **쓰는 이**: 사람 (기여자). 외부 서비스 UI 변경 시 수정합니다.
- **규칙**: UI 변경 대응 시 스크린샷·확인 날짜를 기록하고,
  상단 `마지막 동작 확인` 주석을 갱신하세요 (`CONTRIBUTING.md` 4장).
  브라우저 도구 교체 시 플레이북 형식은 유지하고 실행 주체만 바꿉니다.
