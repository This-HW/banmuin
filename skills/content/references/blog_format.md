# 블로그 글 포맷 가이드

content 스킬이 네이버 블로그 원고를 쓸 때 이 체크리스트를 전부 통과해야 한다.

## 분량
- [ ] 본문 1,200~2,000자 (공백 제외 아님, 전체 글자 수 기준)

## 제목
- [ ] 핵심 키워드 포함
- [ ] 30자 내외
- [ ] 어그로(낚시성 표현) 금지

## 구조
- [ ] 서론: 독자의 상황·고민에 공감하는 문단으로 시작
- [ ] 본문: 소제목 3~5개로 나눔
- [ ] 마무리: CTA 포함 (문의 / 예약 안내)
- [ ] 이미지 3~5장 포함 (본문 흐름에 맞는 위치에 배치, 파일명은 에셋 명명 규칙 준수)

## SEO
- [ ] 핵심 키워드가 제목·첫문단·소제목에 배치됨
- [ ] 키워드를 문맥에 맞게 사용 (무의미한 반복 삽입 금지)

## 금지 사항
- [ ] 동일 문장·문단 반복 금지
- [ ] 타 채널(스레드·인스타 등)에 발행한 글을 그대로 복사 금지 — 블로그용으로 재작성 필수
- [ ] 근거 없는 "1위"·"최고"·"유일" 표현 금지
- [ ] `businesses/<slug>/knowledge/06_브랜드보이스.md`의 금지어 미포함
- [ ] 지식파일에 없는 효능·가격·사례를 지어내지 않음

## 검수 연계
- 이 체크리스트는 품질 게이트 1차 검수(규칙 기반)의 블로그 항목으로 그대로 사용된다.
