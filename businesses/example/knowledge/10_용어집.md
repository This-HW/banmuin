# 10_용어집

> **가상 데이터**: 드라이런 데모용으로 만든 허구 정보입니다.
> 업계 용어를 통일하는 파일이다. 콘텐츠에서 용어를 쓸 때 이 정의를 따른다.

| 용어 | 정의 |
|---|---|
| 핸드드립 | 손으로 물을 부어 천천히 내리는 커피 추출 방식. 원두의 맛을 섬세하게 살릴 수 있다 |
| 싱글오리진 | 한 농장·한 지역에서 수확한 단일 원두. 개성 있는 향미가 특징이다 |
| 블렌드 | 여러 원두를 섞은 것. 균형 잡힌 맛을 내기 위해 조합한다 |
| 콜드브루 | 찬물로 12시간 이상 천천히 우려낸 커피. 쓴맛이 적고 부드럽다 |
| 디카페인 | 카페인을 제거한 원두. 저녁에도 부담 없이 마실 수 있다 |
| 아인슈페너 | 진한 커피 위에 생크림을 올린 오스트리아식 메뉴 |
| 바스크치즈케이크 | 겉을 진하게 구워 카라멜 향이 나는 스페인식 치즈케이크 |
| 라스트오더 | 주방·바 마감 전 마지막으로 주문을 받는 시간 |
