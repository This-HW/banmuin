# 카드뉴스 포맷 가이드

content 스킬이 인스타그램 캐러셀용 카드뉴스를 만들 때 이 체크리스트를 전부 통과해야 한다.

## 규격
- [ ] 1080×1350 px (4:5)
- [ ] 5~10장

## 구조
- [ ] 표지 1장: 한 줄 훅 (궁금증·공감·숫자 중 하나)
- [ ] 본문 3~7장: 장당 하나의 메시지, 문장은 짧게
- [ ] CTA 1장: 문의·예약·저장 유도 중 하나

## 한글 텍스트 처리 (필수)
- [ ] 배경 이미지만 AI 생성 (Higgsfield) — 한글 텍스트를 이미지 생성 모델에 직접 만들지 않는다
- [ ] 문구는 `cardnews_template.html`에 얹어 Aside 작업(`playbooks/cardnews-render.task.md`)으로 PNG 렌더링
- [ ] 장당 글자 수: 제목 20자 이내, 본문 60자 이내 권장 (가독성)

## 디자인 일관성
- [ ] 전 장에 동일한 폰트·색상·여백 사용 (템플릿 기준)
- [ ] 페이지 번호 표기 (`{{페이지번호}}` 플레이스홀더)

## 금지 사항
- [ ] 이미지 생성 모델에 한글 텍스트를 직접 그리게 하지 않음
- [ ] 근거 없는 주장·과장 표현 금지
- [ ] `businesses/<slug>/knowledge/06_브랜드보이스.md`의 금지어 미포함

## 검수 연계
- 이 체크리스트는 품질 게이트 1차 검수(규칙 기반)의 카드뉴스 항목으로 그대로 사용된다.
- 렌더링된 PNG는 2차 검수(AI)에서 가독성·오탈자를 확인한다.
