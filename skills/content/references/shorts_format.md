# 숏폼 포맷 가이드

content 스킬이 YouTube Shorts용 숏폼을 만들 때 이 체크리스트를 전부 통과해야 한다.

## 분량
- [ ] 15~60초 (60초 초과 시 Shorts 분류 불가)

## 장면표 (필수 작성)
매 장면 아래 5개 항목을 채운다:

| 장면 # | 화면 설명 | 대사·내레이션 | 자막 | BGM |
|---|---|---|---|---|
| 1 | … | … | … | … |

- [ ] 장면 수는 3~8개 권장
- [ ] **첫 3초에 훅 필수** (질문·반전·시각적 임팩트 중 하나)

## 제작·핸드오프
- [ ] 영상 생성: Higgsfield MCP
- [ ] 생성된 파일 다운로드 → `businesses/<slug>/assets/YYYY-MM-DD/`에 저장 (명명 규칙 준수)
- [ ] 생성 프롬프트는 sidecar JSON(`*.prompt.json`)으로 함께 저장
- [ ] 자막 편집은 별도 도구에서 (이 스킬 범위 밖)
- [ ] YouTube 업로드 시 `#Shorts` 태그 포함, 60초 이하 확인

## 금지 사항
- [ ] 근거 없는 주장·과장 표현 금지 (대사·자막 모두)
- [ ] `businesses/<slug>/knowledge/06_브랜드보이스.md`의 금지어 미포함 (대사·자막 모두)
- [ ] 저작권 불분명한 음원·영상 소스 사용 금지

## 검수 연계
- 장면표는 품질 게이트 2차 검수(AI)에서 근거·과장·톤을 확인한다.
- 렌더링된 영상은 업로드 전 1차 검수의 규격(길이·비율) 항목을 통과해야 한다.
