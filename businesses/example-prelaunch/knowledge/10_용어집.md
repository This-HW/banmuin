# 10_용어집

> **가상 데이터**: 드라이런 데모용으로 만든 허구 정보입니다.
> 콘텐츠에서 쓰는 용어의 정의. 사장님 눈높이 설명을 기준으로 한다.

| 용어 | 정의 (사장님용 설명) |
|---|---|
| 사전예약 | 정식 오픈 전에 미리 신청하는 것. 얼리버드 30% 할인이 적용됨 |
| 얼리버드 | 사전예약 기간에만 주는 30% 할인 혜택 |
| 베타테스터 | 정식 오픈 전 서비스를 먼저 써보고 피드백을 주는 10명 (모집 중) |
| 프롬프트 | AI에게 일을 시키는 문장. "이렇게 말하면 돼요" 수준으로 설명 |
| 자동화 | 사람이 매번 하던 일을 AI가 대신 처리하도록 만들어두는 것 |
| 로드맵 | 무엇을 어떤 순서로 도입할지 적은 계획표 (컨설팅 결과물) |
| 팔로업 | 컨설팅 2주 뒤 적용 상태를 점검하는 30분 상담 |
| DM | 인스타그램 다이렉트 메시지. 사전예약 신청 채널 |
